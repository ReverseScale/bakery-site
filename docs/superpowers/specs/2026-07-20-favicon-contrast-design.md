# Bakery favicon 对比度优化设计

## 背景

网站已经通过 `index.html` 引用 `public/favicon.svg`。当前立方体使用固定浅色描边 `#f4f4f5`，在浏览器浅色标签页上对比度不足，因此图标看起来接近透明。

## 目标

- 保留现有立方体品牌轮廓，不引入新的品牌图形。
- 在浏览器浅色和深色主题下均保持清晰可辨。
- 继续使用单个 SVG favicon，避免维护多套位图资源。

## 方案

在 `favicon.svg` 内为图标路径设置深色默认描边，并通过 `prefers-color-scheme: dark` 媒体查询切换为浅色描边。`index.html` 继续使用现有相对路径，兼容自定义域名及 GitHub Pages 子路径部署。

未采用固定深色方案，因为它在深色标签页上仍会丢失对比度；未采用实心底板方案，因为它会改变当前极简线框图标的视觉风格。

## 验证

- 增加自动化测试，断言 HTML 仍引用 SVG favicon，并且 SVG 同时声明默认深色与深色模式浅色描边。
- 执行完整测试和生产构建。
- 检查生成后的 `dist/index.html` 与 `dist/favicon.svg`，确认部署产物包含正确引用和颜色规则。
