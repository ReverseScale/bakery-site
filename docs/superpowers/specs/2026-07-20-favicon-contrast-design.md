# Bakery favicon 对比度优化设计

## 背景

网站已经通过 `index.html` 引用 `public/favicon.svg`。当前立方体使用固定浅色描边 `#f4f4f5`，在浏览器浅色标签页上对比度不足，因此图标看起来接近透明。

## 目标

- 保留现有立方体品牌轮廓，不引入新的品牌图形。
- 在浏览器浅色和深色主题下均保持清晰可辨。
- 继续使用单个 SVG favicon，避免维护多套位图资源。

## 方案

在 `favicon.svg` 内增加深色圆角底板，并在其上保留浅色立方体轮廓。双色构图不依赖 `prefers-color-scheme`，因为系统主题与浏览器标签栏的实际底色可能不一致。`index.html` 继续使用现有相对路径，兼容自定义域名及 GitHub Pages 子路径部署。

未采用固定单色描边，因为它只能保证在一种标签栏底色上清晰；未采用主题媒体查询，因为浏览器可能在白色标签栏中仍报告深色系统主题。圆角底板延续网站的深色品牌色，并让立方体轮廓在两种背景上都保持可见。

## 验证

- 增加自动化测试，断言 HTML 仍引用 SVG favicon，并且 SVG 同时包含深色底板与浅色立方体轮廓。
- 执行完整测试和生产构建。
- 检查生成后的 `dist/index.html` 与 `dist/favicon.svg`，确认部署产物包含正确引用和双色图标。
